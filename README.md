# 🎮 Catch the Ball — Neon Arcade Game

A neon-style arcade game built with **C# and Windows Forms**. Move the player platform to catch the falling ball, earn points, and challenge yourself as the difficulty increases.

## ✨ Features

- 🎯 **Catch the Ball:** Move the platform to catch the falling ball.
- 🏆 **Score System:** Earn points for every successful catch.
- ❤️ **Lives System:** Start with three lives and try to achieve your highest score.
- 📈 **Progressive Difficulty:** The game becomes more challenging as you progress.
- ⏯️ **Start and Pause:** Control your game session.
- 🔄 **Restart:** Start a new game after Game Over.
- 🌌 **Neon Arcade Design:** Dark background, glowing colors, and a grid-inspired game area.

## 🛠️ Built With

- **C#**
- **.NET 9**
- **Windows Forms**
- **Visual Studio Code**

## ▶️ Getting Started

### Requirements

- Windows
- .NET 9 SDK
- The project files in this repository

### Run the Game

1. Clone or download this repository.
2. Open the project folder containing `SAEK_Game_Project.csproj`.
3. Open a terminal in that folder.
4. Build the project:

   ```bash
   dotnet build SAEK_Game_Project.csproj
   ```

5. Run the game:

   ```bash
   dotnet run --project SAEK_Game_Project.csproj
   ```

## 🎮 How to Play

1. Start the game.
2. Move the player platform to catch the falling ball.
3. Earn points and progress through increasingly challenging levels.
4. Avoid missing the ball, because you have only three lives.
5. Try to achieve your best score!
